# Como Rodar o Código:
```
1. Clone o repositório: git clone https://github.com/seu-usuario/assembly-x86.git
cd assembly-x86

2. Compile o código Assembly: nasm -f elf64 hello.asm -o hello.o

3. Linke o objeto gerado: ld hello.o -o hello
 
4. ./hello

Você verá a saída correspondente ao seu código Hello World no terminal.
```
